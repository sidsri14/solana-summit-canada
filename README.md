# 🍁 Solana Summit Canada (Toronto 2026) — Creator Hub & Ecosystem Radar

> **Bilingual (English / Français) Intelligence Hub, Teleprompter Studio & Content Launchpad for Solana Summit Canada.**  
> Built for the official **Solana Summit Canada Creator Challenge ($10,000 USDG Pool)** on [Superteam Earn](https://superteam.fun/earn).

---

## ⚡ Overview

**Solana Summit Canada (Toronto, Sep 23–24, 2026)** gathered global founders, institutional allocators, and core engineers to accelerate Canadian Web3 adoption on the SVM.

This platform serves as a complete **Ecosystem Intelligence Engine & Creator Studio**, providing:
1. **7-Category Creator Strategy Matrix**: Pre-engineered threads, hooks, and video scripts across 7 distinct summit tracks (Why Canada, Why I'm Going, Speaker Spotlights, Agenda Navigator, Builder Demos, Sponsor Showcase, Retrospective).
2. **Interactive Teleprompter Studio**: Real-time adjustable speed teleprompter for creators recording video submissions in both English and French.
3. **Bilingual Localization (EN / FR)**: Native French and English copy recognizing Canada's bilingual ecosystem.
4. **Speaker & Institutional Breakdown**: Structured key takeaways from Coinbase Canada, Purpose Investments, and Uniblock on Canadian crypto ETF liquidity and SVM consumer applications.

---

## 🛠️ Architecture & Tech Stack

- **Framework**: React 19 + TypeScript + Vite
- **Styling**: Tailwind CSS with Canadian Maple/Neon Dark aesthetic
- **Features**: Real-time teleprompter speed controller, dynamic copy-to-clipboard, bilingual locale switcher
- **Type Safety**: 100% strict TypeScript verified via `tsc -b`

## 🚀 Running Locally

```bash
# Clone the repository
git clone https://github.com/sidsri14/solana-summit-canada.git
cd solana-summit-canada

# Install dependencies
npm install

# Start local server (Port 5190)
npm run dev
```
